INSIST
一个把「我在坚持」变成「我已经积累了多少」的技能成长账本。
它不催你打卡，它记录你变强的证据。
论坛配套 · 五端同步 · 2026

Why

学习最难的，不是开始，是「看不见自己在变强」

01

学完就忘

书看完了、课刷完了，三个月后只剩一句「我好像学过」。没有复习节奏，知识自己蒸发。

02

目标空转

「我要学 Rust」「我要健身」，写下来就完事。没有拆解、没有阶段、没有反馈，永远停在第一周。

03

进度不可见

待办 App 只会告诉你「还有 7 件事没做」，不会告诉你「你已经比三个月前强了一个段位」。

于是坚持变成一种感觉：今天状态好就觉得自己很行，状态差就怀疑一切。 INSIST 想做的，是把这种感觉换成可以查的账。

Positioning

一句话：它不是待办清单，是技能成长账本

普通待办 / 打卡 App

  • 任务是「消耗品」，做完就消失
  • 只统计「今天做了没」
  • 越用越焦虑：永远有一堆没做
  • 没有积累，没有段位，没有遗忘
  • 数据留在 App 里，朋友圈发不出去

INSIST

  • 任务是「原料」，做完成长进技能里
  • 统计「积累了多少、忘掉了多少」
  • 越用越有成就感：看得见段位和等级
  • 有遗忘度、有衰减、有晋升考试
  • 一键把本周进度发成论坛帖子

核心只有四个字：技能 · 卡片。技能是你的长期资产，卡片是喂养它的日常动作。

Model · Skill

技能：一个技能 = 一条成长曲线

每个技能有自己的段位（你要多用力）和等级（你练到哪了），XP 只在这一段里累积。

段位含义对应的日常投入
低阶入门尝试每天十几分钟
中阶稳定练习每天半小时以上
高阶认真投入要出作品、要复盘
臻阶长期主线半年以上的主线目标

等级：初识 → 入门 → 熟练 → 精通 → 专家，对应 XP 门槛 0 / 100 / 300 / 700 / 1300。

遗忘度 8%
上次活跃 9 天前 · 重要程度：重要（复习间隔 60 天）

Model · Card

卡片：四种形态，覆盖从「今天」到「今年」

habit

习惯卡

每天/隔天打卡。养的是连续性，不是爆发力。

例：刷两道算法题、写 200 字。

task

任务卡

有明确完成标准的一次性动作。

例：看完 CS61B 第六章、配好开发环境。

project

项目卡

需要多个步骤和产出的作品。

例：手写一个 KV 存储、做一个博客。

achievement

成就卡

里程碑，通常由系统自动颁发。

例：连续 100 天、首个项目上线。

卡片也有段位

低阶 / 中阶 / 高阶 / 臻阶。卡片段位决定它值多少 XP，也决定它能不能推动当前技能。

门槛规则

卡片段位 ≥ 技能段位，进度才算数。想升段，就得做更难的事，而不是重复刷简单的。

完成即入账

打卡或完成任务，XP 自动记到对应技能，同时留一条记录，可回溯「这周到底做了什么」。

Mechanics · Daily

打卡不是线性加分，而是一条会「变慢」的曲线

目的很明确：奖励长期，抵抗心血来潮。前几天涨得快，越往后单位收益越低，逼你把时间投到更难的事上。

技能段位打卡一次的基础 XP
低阶1.5
中阶3.5
高阶12.0
臻阶24.0

高段位的技能本身就是稀缺投入，所以单位时间给得多。

累计打卡天数收益系数
不满 7 天× 1.00
7 – 29 天× 0.85
30 – 99 天× 0.62
100 – 199 天× 0.45
200 天以上× 0.30

连续性奖励

连续 7 天 ＋20 XP　　连续 30 天 ＋80 XP　　连续 100 天 ＋300 XP

结果：想靠「今天突击 20 次打卡」刷级是刷不动的，系统只认连续的、跨周跨月的时间。

Mechanics · Decay

会遗忘的进度，才是真进度

遗忘度

距上次活跃越久，遗忘度越高，提醒你该复习了。

重要程度复习间隔
次要180 天
一般120 天
重要60 天
核心30 天

核心技能 30 天不碰，遗忘度就满格 —— 它逼你诚实。

爆满与溢出

当前段位练满（比如 700 / 700）后，继续投入只按比例溢出，剩下的必须靠晋升释放。

爆满持续时长溢出倍率
不满 7 天10% / 天
7 – 29 天5% / 天
30 天以上2% / 天

变相拒绝「在一个舒适段位无限刷经验」。

遗忘度和溢出，是 INSIST 和「打卡游戏」最大的区别：它允许你退步，所以进步才有意义。

Mechanics · Promotion

晋升不是点按钮，是交作业

从「熟练」往上，光有 XP 不够，必须拿完成的作品来换段位。

系统会自动核对清单：哪一项差几张、还差多少，页面上一目了然。凑齐才能晋升，晋升后段位上限提高、每日打卡收益也提高。

Assist

AI 复盘：把数据翻译成人话

系统本来就有全部原始数据：本周 XP、每天的打卡、每张卡的进度、每个技能的遗忘度。

AI 复盘做的事，是把这些数字读一遍，回答三个问题：

  • 这周真正推进了什么？
  • 哪里在空转、哪里快忘了？
  • 下周只做一件最重要的事，做什么？

它不负责鼓励，负责指出问题。

复盘输出示意

「本周 +126 XP，主要来自 Rust 的两次任务卡；但数据结构已 62 天未活跃，遗忘度 51%， 下周优先复习一次；手写 KV 项目卡停在 65%，建议拆成两个 2 小时任务推进。」

Highlight · Share

重点功能：一键把进度「发帖到论坛」

INSIST 里有一个按钮：发布本周总结。 点下去，它把这一周的所有数据整理成一篇 Markdown 帖子，直接发到 DISI 论坛，并给你回链。

01读取当前进度：本周 XP、打卡 x/7、连续天数、技能列表、今日打卡、进行中的卡
02拼成 Markdown：标题 + 本周概览 + 技能 / 今日打卡 / 进行中三个小节
03调用论坛发帖接口，正文一次提交
04回填标签：因为正文里的 ## 会被误抽成标签，发完再 PATCH 覆盖成 INSIST / 学习
05拿到帖子 id，页面出现「已发布到论坛」和帖子链接

为什么不是截图

截图不能搜索、不能被回复、不能积累。帖子可检索、可讨论、可被点赞。

为什么发到论坛

给自己留下公开的复盘记录，也给朋友一个「知道你在干什么」的入口。

为什么能一键

数据本来就在系统里，人只需要决定「发不发」，不需要重新写一遍。

INSIST学习

固定结构，省掉「怎么写复盘」

标题固定为 INSIST 进度 · 日期，正文三段固定：技能 / 今日打卡 / 进行中。 时间久了，论坛里就是一条按周排列的成长曲线。

数据全部来自真实记录

不是让你手填，是系统算出来的：XP 来自打卡与任务，遗忘度按上次活跃推算，进度来自卡片本身。

一个容易被忽略的细节

论坛会从正文里自动抽 #标签，而 Markdown 的 ## 小标题会被误抽成一个 #。 所以发帖之后会再补一次标签覆盖，保证帖子干净地落在「INSIST / 学习」下面。

Implementation

整段逻辑，不到 50 行

// 把当前进度整理成一篇帖子，发到论坛
async function publish() {
  const ymd = today()

  const lines = []
  lines.push(`## INSIST 进度 · ${ymd}`)
  lines.push(`**本周** +${weekXp} XP · 打卡 ${checkDays}/7 · 连续 ${streak} 天`)

  for (const s of skills) {                       // 技能
    lines.push(`- ${s.name}（${tier} · ${level}）${s.xp} / ${total} · 遗忘 ${s.forget}%`)
  }
  // 今日打卡 / 进行中的卡 ……

  const res = await apiCreatePost({
    title: `INSIST 进度 · ${ymd}`,
    content: lines.join('\n'),
    tags: ['INSIST', '学习']
  })

  // 正文里的 ## 会被论坛误抽成标签，补一次覆盖
  await apiUpdatePost(res.id, { tags: ['INSIST', '学习'] })

  publishedId.value = res.id            // 页面出现「已发布」+ 链接
}

三个设计取舍

  • 先发再改标签：比改后端抽取规则省事，也不影响其他帖子。
  • 纯 Markdown、不用图片：五端都能看，以后能按标签做统计。
  • 复用论坛接口：INSIST 不重复造发帖系统，论坛才是内容的家。

延伸可能

同一套数据还能生成月度总结、技能雷达、年度回顾 —— 都是「把已有记录换个说法」。

In Practice

它到底能帮你干什么：五个真实用法

场景怎么用得到什么
备考 / 证书 技能「408 考研」中阶，习惯卡每日 2 小时，任务卡按章节拆，项目卡「真题全刷一遍」 每天看得见的推进；遗忘度提醒你回头复习；考前一段时间的曲线说明一切
转岗 / 技术栈 多个技能并行：Rust 高阶、数据库中阶、系统设计中阶，卡片按「能跑起来的作品」定义 面试时的项目卡就是作品集；晋升清单逼你从教程走向作品
健身 / 生活习惯 低阶技能 + 习惯卡，只看连续天数和边际递减，不追求爆发 把「今天去不去」变成「别断」，连续性奖励比空头承诺有用
读书 / 输入 每本书一张任务卡，读完写复盘；核心技能 30 天复习一次 不会「读完就忘」，遗忘度就是复习日程
副业 / 长期项目 臻阶技能 + 项目卡，每周发一次进度帖到论坛 公开记录带来外部监督，帖子本身也是持续输出的素材

后端

FastAPI + SQLite，规则集中在 insist_rules.py：段位、XP、递减、溢出、晋升清单、遗忘度全部是纯函数，接口层只做读写。

可配置

每个用户都能改数值：等级门槛、每日 XP、衰减曲线、复习间隔、连续奖励 —— 默认值只是起点。

与论坛的关系

同一套账号体系、同一个后端。INSIST 负责积累，论坛负责公开，两者靠「发帖」这个动作连起来。

它不是又一个记录工具，而是把技能成长这件抽象的事，做成了一套能查、能算、能发的系统。
